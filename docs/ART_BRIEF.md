## 0. 游点灵怎么用
1. 打开 `https://craft.qq.com/chat`，进入 **2D 图片 / 图片生成**；找不到入口就直接在对话里说“用国风风格生成 1:1 的 2D 图片”，再粘贴描述。
2. 类型：卡牌选 **通用**；背景/事件/结局选 **背景图**；标题不建议用 AI，见第 4 节。
3. 风格：选 **国风**；如果没有这个选项，prompt 开头已经写了“国风水墨仙侠”。
   如果卡牌生成界面有 **「背景去除」** 开关，打开它；这样能直接出透明底。没有就用纯色深墨绿 `#0c1411`，两种我都能接入。
4. 比例：卡牌 **1:1**；背景/事件/结局 **16:9**。分辨率选 **720P 或 1080P**。
5. 粘贴下面的中文 prompt；一次多出几张，挑一张最稳的。
6. **第一张满意后**，点「用作参考」或把图附给 AI，后面每张先说：
   “严格保持参考图的画风、色调、笔触和构图，只把主体换成下面描述。”
   这比换 seed 更稳，能明显减少风格漂移。
7. 下载 PNG；按 `id.png` 命名，放到 `public/assets/...`。

> 如果输入框有长度限制：保留“主体 + 构图 + 色调 + 背景”，把最后一句“画面不要出现…”放到备注/负面词，效果基本不变。

> 游点灵如果有 **「背景去除」** 开关，卡牌建议打开，直接出透明底；没有就统一用纯色深墨绿 `#0c1411` 底。我两种都能接入，透明图更好。
> prompt 最后一句已经是禁止项；如果工具有单独 Negative Prompt 输入，可以把最后一句再粘过去。

## 1. 统一风格锁（重要）
- **国风**：水墨 / 青绿山水，仙侠，克制、清冷、旧纸与香火气。
- **主色**：深墨绿 `#0c1411`、旧金 `#d9b96c`、纸色 `#f3ead6`、印章红 `#8d3029`。
- **光线**：柔和侧光 / 晨雾 / 月光；不要霓虹、强饱和、现代物件。
- **卡牌构图**：1:1，主体居中，边缘留 8% 安全区；缩到 64px 仍能读出轮廓。
- **一致性**：同一模型、同一“国风”预设、同一张参考图；不要逐张换 anime / 3D / 写实。
- **禁止**：文字、字母、数字、边框、水印、Logo、UI、照片写实、西方奇幻、过曝。

> UI 图标与卡背暂不需要：当前界面用汉字/符号，卡背也不出现；以后要做图形化图标再补。

## 9. 交付方式
1. 按文件名放进 `public/assets/cards/`、`public/assets/audio/`、`public/assets/events/`、`public/assets/endings/`、`public/assets/video/`。
2. 文件名不同先给我映射表；不要直接覆盖同名文件。
3. 卡图统一纯色深墨绿底即可；如果工具支持透明，也可以给我透明 PNG。
4. **先发 3–5 张样图**（背景、标题、`jiangdao`、`lingtian`；`caishi` 已接入）即可，我接入后给你桌面/手机截图；确认后再批量。
5. 音频先给 1 个 BGM + 1 个出牌音效即可试听；视频最后做。

## 10. 我会怎么接入
- 卡图：手牌/坊市/八景统一用方形 inset `<img>` + `onerror` 回退到汉字 glyph；纯色深底正好融入暗色面板，不需要抠图。
- 背景：叠加在现有 CSS 山景下方，保留暗色渐变保证文字可读。
- 标题：优先用透明 PNG；如果是深底图，我用 `mix-blend-mode: screen` 去掉暗底。
- 音频：首次用户点击后启动 BGM；抽牌/出牌/购入/事件/胜负分别触发；提供静音按钮。
- 事件/结局图：弹层顶部或结算页背景；没有图时保持现有排版。
- 视频：只在开场/结局按需加载，不阻塞首屏。
