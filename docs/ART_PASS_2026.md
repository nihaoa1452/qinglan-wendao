# 2026-11 美术迭代说明

这次迭代的目标不是“再换几张图”，而是把整款游戏的视觉语言统一成一套：

> 深墨绿夜色 + 青绿灵光 + 旧金线 + 宣纸卡片，画面偏暗、低明度、主体受光。

## 风格锁

- 主色：深墨绿 `#0c1411`、青绿 `#7fb69a`、旧金 `#d9b96c`、印章红 `#8d3029`。
- 光线：夜色、低明度、强侧光；只让主体、剑光或灵光发亮。
- 笔触：浓墨、飞白、宣纸纹理；不要现代物件、照片写实、西方奇幻、过曝。
- 卡牌构图：方形 1:1，主体居中，边缘留 8% 安全区，缩小到 64px 仍可读，不画卡牌边框和文字。
- 战斗构图：横幅 16:9，主体偏左/居中，头部与上半身在画面中央，右侧留出意图文字的位置，边缘压暗。
- 道具构图：方形 1:1，主体占画面约 55%，透明背景，缩小到 48px 仍可读。
- 传承横幅：3:1 宽幅，主体居中完整入画，占画面高度约 70%，四周留 12% 安全区，左右可延展场景。

## 生成参数

- 平台：游点灵（craft.qq.com）
- 模型：`seedream_5_0_pro`
- 卡牌：`1024x1024`，`with_matting: false`（保留夜色背景）
- 敌人 / 场景 / 背景：`1280x720` 或 `1024x1536`，`with_matting: false`
- 道具：`1024x1024`，`with_matting: true`（透明背景）
- 传承横幅：`1536x512`，`with_matting: false`
- 标题字：`1024x1024`，`with_matting: true`

## 后处理

脚本处理在临时目录完成，成品直接写入 `public/assets/`：

- 卡牌：缩到 512×512，加 22% 径向暗角，对比度 +3.5%，饱和度 +2%，JPG q90。
- 敌人 / 场景：缩到 1280×720，加 16% 暗角，JPG q88–90。
- 标题背景：放大到 1600×900，加 20% 暗角，亮度 ×0.92。
- 道具：裁掉透明边，等比缩到 440px，再补成 512×512 透明 PNG。
- 传承横幅：缩到 1200×400（3:1），加 16% 暗角，对比度 +3%，JPG q88。
- 标题字：裁掉透明边，四周留 24px。

## 复现

1. 把生成任务写成 JSON（字段：`name`、`prompt`、`size`、`with_matting`），参考 `shots/artgen/card-jobs.json`、`scene-jobs.json`、`meta-jobs.json`。
2. 运行 `node scripts/artgen.mjs --jobs <jobs.json> --out <dir> --concurrency 6`。
3. 结果和游点灵资源 id 会写入 `<dir>/manifest.json`，再去 `docs/ASSET_MAP.md` 查/补映射。
4. 运行 `python scripts/process-art.py`：按固定规格裁切、压暗角、补透明边，写入 `public/assets/`。
5. 代码只认文件名，不需要改接口。

## 接入位置

- `src/game/assets.ts`：卡图、敌人图、道具图、背景/场景 URL。
- `src/sts/data.ts`：卡牌、敌人、遗物、丹药、传承的 `art` 字段。
- `src/sts/ui.ts`：标题、地图、战斗、背包、图鉴、坊市、闭关、结局的图片引用。
- `src/sts-art.css`：卡框、暗色画窗、地图卷轴、战斗舞台、标题卡、移动端覆盖。
- 传承横幅：`src/sts.css` 的 `.sts-meta-card__art` 固定为 3:1，图片 `object-fit: cover`，与出图比例一致，不再裁切主体。

## 已知边界

- 11 张事件图和 2 张结局图仍是 2026-11-10 的旧版，风格与新版同源但笔触略有差异；后续可以按同一模板重做。
