# 青岚问道录 · 设计说明（v0.7.0 垂直切片）

## 目标

把原来的 30 天宗门经营替换成单局卡牌爬塔：

- 一局约 15–25 分钟
- 第一周目 8 行山道，树状分支选路
- 回合制卡牌战斗 + 战后构筑
- 击败山道尽头妖王即胜利，气血归零则失败
- 通关进入下一周目；局外道蕴商店提供永久传承

玩法类型受《杀戮尖塔》等作品启发；本项目的卡牌、敌人、地图和数值均为原创，没有复制其具体内容。

## 核心循环

```text
标题
  ↓
地图选节点
  ↓
战斗 → 三选一卡牌奖励 → 返回地图
  ↓
异闻 / 闭关 / 坊市
  ↓
山道尽头妖王 → 胜利 / 失败
  ↓
周目 +1 / 道蕴结算 → 传承商店 → 下一局
```

## 战斗规则

- 玩家初始气血 80。
- 每回合 3 点灵力，抽 5 张牌，手牌上限 10。
- 打出的牌进入弃牌堆；消耗牌进入消耗堆。
- 结束回合后：
  1. 弃掉非“保留”手牌；
  2. 中毒在敌方回合开始时结算；
  3. 敌方按意图行动；
  4. 剩余格挡清零，灵力回满，抽 5 张牌。
- 玩家攻击伤害 = 卡牌伤害 + 力量；玩家虚弱时 ×0.75，敌方破甲时 ×1.5。
- 敌方攻击伤害 = 招式伤害 + 敌方力量；敌方虚弱时 ×0.75，玩家破甲时 ×1.5。
- 格挡先吸收伤害，剩余扣气血。

## 地图

第一周目 8 行，三列为主，但每局随机洗牌并随机剪枝：

1. 战斗 ×3
2. 战斗 / 战斗 / 异闻（位置随机）
3. 闭关 / 战斗 / 坊市（位置随机）
4. 精英 / 战斗 / 异闻（位置随机）
5. 战斗 / 闭关 / 异闻（位置随机）
6. 精英 / 战斗 / 坊市（位置随机）
7. 闭关
8. 妖王 / 魔焰妖王（随机）

节点只连接下一行相邻列；连边会随机保留，保证每个节点至少有一条进入路线，但不会每局都长成同一棵树。

周目会在地图末尾（最终闭关之后）插入额外节点行，并提高敌人属性：

| 周目 | 地图行数 | 敌人气血 | 敌人攻击 |
| ---: | ---: | --- | --- |
| 1 | 8 | 基础 | 基础 |
| 2 | 10 | +16% | +12% |
| 3+ | 12（上限） | 每多一周目继续叠加 | 每多一周目继续叠加 |

周目只影响敌人和地图长度，不改变玩家基础气血、初始牌组和卡牌数值；局外传承负责补偿难度。

## 树状地图

- 节点按行列排布，SVG 线绘制可走的分支；亮起的节点为当前可选路线。
- 单节点行（闭关/妖王）居中，避免路线偏移。
- 前两关不是安全区；敌人会在玩家结束回合后执行意图。

## 节点

- **战斗**：普通敌人，奖励金币 + 三选一卡牌。
- **精英**：魔修或血修，奖励金币 + 卡牌 + 遗物。
- **异闻**：从 11 个事件中随机抽取（云游道人、古洞遗宝、山下时疫、剑冢残鸣、魔音入梦、灵雨普降、商队借宿、散修求助、仙盟征税、紫气东来、邻宗挑衅），每个事件三选一。
- **闭关**：回复 30% 气血，或随机升级一张牌。
- **坊市**：三张随机牌，用灵石购买；可买多张。另有“忘尘茶”，每次坊市可花 50 灵石删除一张牌。
- **妖王**：妖王或魔焰妖王，胜利后结算。

## 周目与局外传承

- 每局结束结算道蕴：胜利 `20 + 楼层×3 + 周目×5`，失败 `5 + 楼层×2 + 周目×3`。
- 胜利后 `meta.cycle = max(meta.cycle, 当前周目 + 1)`；标题页新局从当前周目开始。
- 道蕴与已购传承保存在 `qinglan-sts-meta-v1`，不随单局存档清空。
- 传承商店（藏经阁）当前有 5 项一次性购买：
  - 追风剑谱：初始牌组 +1 追风剑（40 道蕴）
  - 清心诀：初始牌组 +1 清心诀（35 道蕴）
  - 剑心通明：开局携带遗物（60 道蕴）
  - 聚灵散：开局多 1 枚丹药（25 道蕴）
  - 气血淬炼：最大气血 +10（45 道蕴）

## 遗物

- 青岚掌门印：战斗开始获得 4 格挡。
- 青玉葫芦：战斗结束回复 5 气血。
- 剑心通明：战斗开始获得 1 力量。
- 聚灵玉佩：战斗第一回合额外 +1 灵力。

开局拥有青岚掌门印；精英掉落未拥有的遗物。

## 连击与组合

本切片有独立的**连击**计数器：本回合每打出一张攻击牌，连击 +1；追风剑按当前连击追加伤害。回合结束清零。

其他组合：

- 力量 + 多段攻击；
- 破甲放大后续伤害；
- 抽牌/回灵力延长一回合；
- **中毒**在敌方回合开始按层数掉血，无视格挡，然后减 1 层；
- **身法**让每张格挡牌额外获得等量格挡；
- **保留**牌在回合结束时留在手中；
- 功法、消耗牌与遗物叠加。

已实现：多段攻击、力量、破甲、虚弱、格挡、抽牌、回灵力、消耗、遗物、升级、连击、中毒、身法、保留、丹药、坊市删牌。尚未实现：多敌人目标、虚无/固有/无形、球/姿态、完整三幕。

## 战斗反馈与操作

- 点击手牌，或把手牌**拖到对局任意位置**出牌；拖动时整个战斗区域会显示虚线投放区，卡牌半透明抬起。
- 战斗界面为**左右对称布局**：敌手在左、你在右，双方面板等宽。
- **全屏面板**：背包、图鉴、玩法、战斗日志、退出菜单都是全屏展示，并配有卡图、敌人图或场景图。
- 顶部**背包**查看当前牌组、遗物、丹药效果；**图鉴**查看全部 33 张牌的基础/升级效果和当前持有数量。
- **战斗记录**实时显示最近记录；点“展开日志”查看整场战斗，每次敌方行动后生成“上回合结算”，汇总气血损失和剩余格挡。
- 顶部**退出**打开对局菜单；可以保存并返回主界面，也可以结束本局并清空存档。
- 玩家攻击：敌方卡上出现金色斩击、伤害数字与轻震。
- 敌方攻击：玩家卡上出现红色斩击、伤害数字、红色闪屏与重震。
- 格挡、回复、中毒分别有蓝色光环、绿色数字、绿色毒伤数字。
- 战斗界面右上角显示敌人意图；玩家状态栏显示格挡、力量、身法、破甲、虚弱、连击。
- 音效为 Web Audio 合成的 8-bit 风格：界面点击、出牌、斩击、格挡、受伤、回复、中毒、购牌、传承、进入战斗、回合结束与胜负各有短音；标题页和 HUD 可静音。

## 自动平衡

`npm run sim` 运行 100 局简单 bot：优先选战斗节点、按攻击/防御优先级出牌、战后选奖励、低血闭关。

当前基线约 **44% 第一周目通关**。注意 bot 不会像人一样规划路线和构筑，这个数字只用于回归对比。后续调整方向：

- 如果太简单：提高 Boss/精英气血和伤害，增加第二幕。
- 如果太难：提高初始气血或奖励质量，减少精英数量。
