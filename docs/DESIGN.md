# 青岚宗 · 设计文档（v0.2）

> 完整数值表见 `docs/NUMBERS.md` 与 `docs/numbers/青岚宗数值清单-v0.2.xlsx`。

## 1. 核心循环

```text
清晨抽 5 张牌 + 刷新坊市（1 行动 + 1 设施） + 随机事件弹层
        ↓
点击或拖拽手牌到八景，花灵石打出（行动牌结算 / 设施牌留场）
        ↓
可购入坊市卡牌（进入弃牌堆）；可换一批未售出货位
        ↓
结束今日：设施产出 + 弟子净收入 → 胜利/日终破产检查 → 下一天
        ↓
声望 ≥ 600 胜利；日终结算后灵石 < 0 解散；第 30 天结束未达标超时
```

设计意图：

- **输入随机**：抽牌与坊市随机改变计划，但打牌结果确定。
- **延迟收益**：设施需要 3–5 天回本，逼迫玩家在“现在买声望”和“投资未来”之间取舍。
- **现金流压力**：事件可能把灵石打到负数；日间可用免费牌自救，日终仍为负才失败。
- **组合成长**：弟子 → 演武场；药园 ↔ 丹房；藏经阁 ×N → 讲道。
- **短局**：30 天上限，当前节奏约 20–27 天。

## 6. 规则细节

### 牌堆与弃牌堆

- 抽牌堆用尽时，弃牌堆洗回继续抽。
- 行动牌结算后进入弃牌堆。
- 设施牌打出后从牌组永久移除，转为已建成设施，占 1 个位置。
- 设施位满后，设施牌**禁止打出**（默认方案 A），点击会提示“八景已满”。

### 藏经阁叠加

- `讲道` 声望 = `2 + 2 × 藏经阁数量`。
- 0 座 = 2；1 座 = 4；2 座 = 6；4 座 = 10。
- 藏经阁自身的每日 +2 声望独立计算。

### 弟子与设施叠加

- 弟子数量无上限。
- 演武场按 `floor(弟子数 / 2)` 计算每座每日声望，多座独立叠加。
- 药园有丹房时每日总产出 +3（不是 1+3）。
- 山门每座每 3 日 +1 弟子。
- 同名设施可重复建造。

### 坊市

- 每天 1 张行动牌 + 1 张设施牌，两个货位独立抽取。
- 行动池 15 张（7/6/2），设施池 9 张（4/3/2）。
- 购入价 = 卡牌费用；购入牌进入弃牌堆。
- 换货 2 灵石，只重抽未售出的货位；两个都售罄时按钮禁用。
- 同一天两个货位不会重复。

### 事件与破产

- 第 3 日起每日 35%；距上次事件满 3 天必触发。
- 抽取前剔除不满足最早天数的事件。
- 事件弹层显示名称、效果、确认按钮；若当前灵石为负，提示“日终仍为负会解散”。
- 事件损失可把灵石打到负数，但**不会立即失败**。
- 日间可打出费用为 0 的牌自救；费用 > 0 的牌仍不可打出。
- 日终结算后：
  1. 先检查声望 ≥ 600 → 胜利；
  2. 再检查灵石 < 0 → 破产；
  3. 再检查第 30 天 → 超时。

## 8. 自动平衡结果（目标 600）

500 局/策略，目标 600：

| 策略 | 胜率 | 破产率 | 超时率 | 平均胜利天数 |
| --- | ---: | ---: | ---: | ---: |
| 贪心（见牌就打） | 58.6% | 12.0% | 29.4% | 27.1 |
| 保留 10 灵石 | 48.6% | 3.2% | 48.2% | 27.4 |
| 保留 15 灵石 | 42.2% | 2.2% | 55.6% | 27.4 |
| 保留 20 灵石 | 38.6% | 2.2% | 59.2% | 27.6 |
| 保留 8 + 天数 灵石 | 40.6% | 1.6% | 57.8% | 27.4 |
| 保留 10 + 1.5×天数 灵石 | 38.2% | 0.6% | 61.2% | 27.7 |

结论：300 目标下贪心胜率 90.8%，明显偏宽松；把标准目标提高到 600 后，贪心胜率降到 58.6%，平均胜利天数推到 27.1 天，超时和破产开始成为真实压力。保留灵石的保守打法反而更容易超时，说明当前版本鼓励积极投资设施与声望，而不是一味囤钱。

若仍觉得偏松，下一步优先提高事件强度或缩短天数；若偏硬，可回落到 550 或改成难度选择。

## 9. 可扩展方向

- 卡牌升级：同一设施 2–3 级，改变产出或解锁联动。
- 弟子个体：资质/境界，可派驻设施。
- 宗门科技：用声望解锁树。
- 事件选择：事件弹层给 2 个选项（花钱消灾 / 冒险）。
- 难度选择：休闲 300 / 标准 600 / 挑战 750，或缩短天数。
- 云存档 / 在线排行榜 / UI 编辑器 / 场景编辑器：需要后端与工具链，建议单局玩法稳定后单独排期。
