# 青岚问道录

一个修仙题材的单机卡牌爬塔游戏。你带着一卷残剑谱与十张旧牌，沿青云山道向上，击败山道尽头的妖王；通关后还能进入更长、更强的下一周目。

- Vite 7 + TypeScript + 原生 DOM/CSS，无游戏引擎
- 桌面优先，手机/平板自适应
- 单局约 15–25 分钟；死亡后从头再来
- 2026-11-11 完成美术迭代：33 张卡图、10 个敌人场景、玩家立绘、标题/山道背景、闭关/坊市场景、7 个道具图标、5 张传承横幅与标题字全部重做
- 8-bit 风格音效：出牌、攻击、格挡、受伤、回复、购牌、传承、胜负等均由 Web Audio 实时合成，无外部音频文件；标题页与 HUD 可开关
- 玩法结构受《杀戮尖塔》等卡牌爬塔游戏启发；**具体卡牌、敌人、地图与数值为本项目原创**，没有复制原作的关卡数据或文本

> 旧的“30 天宗门经营”玩法已被替换。旧版代码与文档仅作为历史保留，不再从入口加载。

## 快速开始

需要 Node.js 20+。

```bash
npm install
npm run dev
```

打开终端给出的地址（默认 `http://localhost:5173/`）。构建静态版本：

```bash
npm run build
npm run preview
```

## 玩法

1. **从山道中选路**：第一周目 8 行，第二周目 10 行，之后最多 12 行；战斗、精英、异闻、闭关、坊市、妖王。
2. **战斗**：每回合 3 点灵力、抽 5 张牌；打出攻击 / 防御 / 功法牌，然后结束回合。
3. **破甲**使受到的攻击伤害提高 50%，**虚弱**使造成的攻击伤害降低 25%，**格挡**在回合开始时清空。
4. **战后三选一**：把新牌加入牌组；灵石可在坊市买牌。
5. **闭关**：回复 30% 气血，或随机升级一张牌。
6. **精英**掉落遗物；**妖王**在山道尽头，击败后本局胜利，并解锁下一周目。
7. 气血归零则本局失败。进行中的对局会自动保存，标题页可以继续；通关或失败后本局存档清空。

### 地图与连击

- 地图现在是**树状分支**：每次开局的节点类型、位置连线和分支走向都会变化；节点之间的金线表示可走路线，亮起的节点可以前进。
- 前两关的敌人**会正常攻击**；它们会在你点“结束回合”后按红框里的意图行动。看起来没掉血通常是因为格挡吸收了伤害。
- **格挡不是只挡一次盾**：它先吸收敌方攻击，盾不够就打气血；敌方行动结束后，剩余格挡会在你的下一回合开始时清空。
- **敌人意图显示的是实际攻击数字**：已经计入敌方力量和你身上的破甲；悬停可以看到“基础伤害 + 力量”等明细。
- 《杀戮尖塔》的连击主要来自卡牌之间的配合：力量 + 多段攻击、破甲 + 高伤害、抽牌/回灵力延长回合、功法/遗物叠加。本作在此基础上额外加入独立的**连击计数器**：
  - 本回合每打出一张攻击牌，连击 +1；
  - **追风剑**按当前连击追加伤害；
  - 回合结束清空。
- 当前版本已实现：多段攻击、力量、破甲、虚弱、格挡、抽牌、回灵力、消耗、遗物、升级、战后构筑。
- 新增机制：**连击**、**中毒**（敌方回合开始按层数掉血）、**身法**（格挡牌额外格挡）、**保留**（回合结束不弃牌）、**丹药**（回春丹/聚灵散/破障丹）、**坊市忘尘茶**（删牌）。
- 战斗反馈：攻击有斩击、伤害数字和屏幕震动；受击有红色闪屏和重震；格挡、回复、中毒也有独立数字/光环。出牌支持**点击或拖到对局任意位置**。
- **战斗记录**：战斗界面实时显示最近记录，点“展开日志”查看整场战斗；每次敌方行动后会生成“上回合结算”，汇总气血损失和剩余格挡。
- 尚未搬来：多敌人目标选择、虚无/固有/无形等关键词、球/姿态类职业机制、三幕完整内容。后续可以继续补。

### 周目与传承

- 每局结束按到达层数与周目结算**道蕴**；胜利获得更多，并解锁下一周目。
- 下一周目山道更长（10 行，之后 12 行），敌人的气血与攻击随周目提高；已获得的道蕴和传承会保留。
- 标题页的**传承**是局外成长商店：用道蕴永久购买追风剑谱、清心诀、剑心通明、聚灵散、气血淬炼，下一局开局生效。
- 通关页可以直接“进入下一周目”；标题页也会从当前周目开始新局。

### 当前位置

- 第一周目 8 行节点；第二周目 10 行；之后最多 12 行
- 33 张卡牌（3 类初始牌 + 30 张奖励/坊市牌）
- 11 个异闻事件（云游道人、古洞、时疫、剑冢、魔音、灵雨、商队、散修、仙盟、紫气、邻宗）
- 10 种敌人（6 普通、2 精英、2 妖王；每局随机抽取）
- 4 件遗物、3 种丹药
- 5 项局外传承（道蕴商店）
- 完整流程：标题 → 随机树图 → 战斗/异闻/坊市/闭关 → 奖励 → 妖王 → 结算

## 操作

- 点击卡牌出牌，或把卡牌拖到对局任意位置出牌；点击“结束回合”进入敌方行动。
- 战斗中点角色卡下方的丹囊服用丹药；丹药不消耗灵力。
- 顶部 HUD 查看气血、灵石、层数、遗物；**背包**、**图鉴**、**玩法**都是全屏面板，带卡图/场景图；背包看当前牌组、遗物和丹药效果，图鉴看全部 33 张牌的基础/升级效果和当前持有数量。
- 战斗区域为**左右对称布局**：敌手在左，你在右，双方面板等宽。
- 顶部**退出**可以打开对局菜单：继续对局、保存并返回主界面、重新开始，或**结束本局**并清空存档。
- 坊市可以买牌，也可以用“忘尘茶”删除一张牌（每次坊市限一次）。
- 支持键盘 `Esc` 关闭玩法/背包/图鉴弹层。
- 标题页右上角与顶部 HUD 的「音效 开/关」可以随时静音，设置会保存在本地；首次点击页面后才会启动音频（浏览器自动播放限制）。

## 数值与设计

- 初始气血 80，初始灵石 80，初始牌组 10 张。
- 初始牌组：5×青锋斩（7 伤害）、4×凝气盾（6 格挡）、1×镇岳剑（8 伤害 + 破甲）。
- 战斗基础：3 灵力 / 每回合抽 5 / 手牌上限 10。
- 卡牌、敌人和地图数据在 `src/sts/data.ts`，规则在 `src/sts/engine.ts`。
- 设计说明见 [docs/STS_DESIGN.md](docs/STS_DESIGN.md)。

当前 100 局自动 bot（只会选战斗节点、按简单优先级出牌）第一周目通关约 **44%**；加入随机地图、新敌人、周目和传承后，后续可以继续调数值。这个数字只用于回归对比，不代表最终难度。

## 已知边界

- 当前是单敌人战斗；没有多敌人站位、多角色；异闻池为 11 个，不是无限随机事件。
- 地图仍是一层山道（周目会增长到 10/12 行），但节点类型、分支和敌人已经随机化；尚没有 3 层/多幕。
- 已加入道蕴商店和周目难度；尚未做可选难度等级与多角色。
- 旧经营模式的 `src/game/`、旧文档和旧 CSV 仍留在仓库中，但入口不再引用；后续可以清理。
